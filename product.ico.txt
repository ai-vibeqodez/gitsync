# Windows Icon Placeholder

For Windows builds, place a .ico file here named `product.ico`.

The icon will be embedded in the gitsync.exe binary via the Windows resource
compiler and will appear in:
- File Explorer
- Taskbar
- Alt+Tab switcher
- File Properties dialog

You can create a .ico file from PNG using:
- Online converters (e.g., https://convertio.co/png-ico/)
- ImageMagick: `convert icon.png -define icon:auto-resize=256,128,64,48,32,16 product.ico`
- GIMP: Export as .ico with multiple sizes

Recommended sizes: 16x16, 32x32, 48x48, 256x256
